About This Website

This website is a class project I made to practice building a multi-page site using only HTML and CSS. I chose "The Amazing World of Gumball" as my theme because it has a large cast of colorful, easy-to-describe characters.

The site has a home page with a character gallery, a details page for one character, an about page, and a form page for adding new characters. The search bar and the form don't actually work yet since this is a static website with no backend.
